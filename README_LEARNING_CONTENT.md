이 폴더는 **초등학생이 쉽게 이해할 수 있는 컴퓨터 OA(Office Application)와 인공지능(AI) 학습 콘텐츠**를 담고 있습니다.

**특징:**
- ✅ 초등학생 눈높이에 맞춘 설명
- ✅ 이론과 실습을 함께 제공
- ✅ 재미있고 흥미로운 예시와 활동
- ✅ 단계별 학습 구성
- ✅ 챗봇 서비스에 바로 활용 가능

**💬 챗봇(ChatBot) 학습 가이드**

주요 내용:
- 챗봇이란?
- 🎯 챗봇의 두 가지 종류
  - 규칙 기반 챗봇 (Rule-Based)
  - AI 기반 챗봇 (AI-Powered)
- 🏢 실생활 속의 챗봇
  - 고객 상담 챗봇
  - 교육용 챗봇
  - 예약 챗봇
- 💭 챗봇이 대화하는 방식
  - 이해 → 정보 검색 → 답변 생성
- 🔧 간단한 챗봇 만드는 법
  - 의사코드 예시
  - 파이썬 코드 예시
- 🎯 좋은 챗봇의 5가지 특징
  - 이해력, 자연스러움, 속도, 오류 처리, 친절함
- 🔐 챗봇 사용 시 주의사항
  - 개인정보 보호
  - 정보 신뢰성 확인
  - 지나친 의존 피하기
- 📝 연습 문제 및 챗봇 체험 활동

**학습 시간**: 약 1-2시간
**대상**: 초등학교 4-6학년

#### 4️⃣ **learning_content_04_practical_activities.md**
**🎮 실전 활동: 직접 해보기!**

5가지 실습 활동:

**활동 1️⃣: 워드로 "나의 동물 카드" 만들기**
- 제목 입력 및 꾸미기
- 이미지 삽입
- 설명 글 추가
- 응용: 반 친구들 5개 카드 만들기

**활동 2️⃣: 엑셀로 "우리 반 키, 몸무게 비교" 표 만들기**
- 표 제목 만들기
- 데이터 입력
- SUM 함수로 합계 계산
- AVERAGE 함수로 평균 계산
- 그래프 만들기

**활동 3️⃣: 파워포인트로 "우리 반 소개" 발표 만들기**
- 슬라이드 구성 (7장)
- 제목, 반 정보, 사진, 친구 소개, 마무리
- 애니메이션 추가
- 발표 연습

**활동 4️⃣: AI 그림 생성기 체험**
- Bing Image Creator 사용
- 다양한 명령어로 그림 생성
- 결과 분석
- 10개 이상 생성 목표

**활동 5️⃣: AI 챗봇과 대화하기**
- ChatGPT 또는 Google Bard 접속
- 다양한 질문 시도
- 답변 평가 체크리스트
- 10회 이상 대화 목표

**학습 시간**: 약 4-5시간
**대상**: 초등학교 4-6학년
